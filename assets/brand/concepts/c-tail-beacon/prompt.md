# Concept C — 鲸尾信标 / Tail Beacon

```text
Use case: logo-brand
Asset type: minimal native desktop application icon concept for macOS and Windows
Primary request: redesign the ImagePorter / 鲸舟 Tail Beacon mark as one compact connected transfer symbol: a broad geometric cyan vessel/chevron silhouette containing one unmistakable deep-navy whale-tail negative-space cutout and exactly one rightward arrow cue
Subject: one unified, horizontally balanced abstract symbol with a stable outer silhouette; the deep-navy tail cutout must have two large symmetrical flukes, a wide central V, and a short broad peduncle, occupying roughly one third of the symbol interior so it remains unmistakable at actual 16 and 24 pixels; the transfer arrow must point right exactly once and integrate into the outer silhouette
Style/medium: strict flat vector-friendly geometry, hard clean edges, minimal, professional developer-tool character, no more than three major shapes total, designed first for actual 16, 24, and 32 pixel rendering
Composition/framing: centered single unified icon system, generous 16 percent safe-area padding on every side, strong balanced negative space, no detached components
Color palette: solid deep navy background and solid ice-blue/cyan symbol only; uniform flat fills with no tonal variation
Constraints: absolutely no separate vertical bar, no stem-and-loop construction, no P-shaped curve, no readable I or P, no visible letters or words, exactly one rightward arrow, whale tail must be negative space rather than a positive shape, no mascot, no mockup scene, no external label, no watermark, no tiny details, no thin outlines, no gradients, no glow, no shadow, no bevel, no texture, do not imitate the Docker whale trademark
```
