# ImagePorter 品牌图标设计规格

## 目标

为“鲸舟 / ImagePorter”设计三套可实际用于桌面软件的品牌图标。三套方案需要在 macOS Dock、Windows 快捷方式、任务栏、README 与应用关于窗口中保持清晰，并能准确传达“Docker 镜像搬运、离线导出、跨架构传输”的产品定位。

## 视觉原则

- 以现代原生桌面应用风格为主，辅以克制的开发者工具气质。
- 方案 A、B 必须出现明确的鲸鱼意象；方案 C 使用鲸尾或鲸身负形保留品牌关联。
- 延续产品现有蓝色主色，并以青色作为强调色；可在方案 B 中少量使用电光紫。
- 图形必须在 16–32 px 下仍可识别，避免细线、复杂透明叠层和依赖文字的构图。
- 不复刻 Docker 官方鲸鱼商标，不使用含义不清的 `DC` 字母。
- 图标内部不放置文字；中英文名称仅用于独立横向品牌组合。

## 三套方向

### A. 鲸舟货舱（推荐）

鲸鱼侧身构成稳定的船体，上方承载 2–3 个简化集装箱方块；鲸身、水线或留白中包含向右的运输动势。整体圆润、可靠，以钴蓝到青色的渐变表现现代感。小尺寸版本简化为“鲸鱼 + 单个方块”。

### B. 跃迁鲸舱

采用正面或 3/4 视角的鲸鱼，托举一个几何镜像包；两条短轨迹表现导出、跨架构和离线迁移。造型比方案 A 更锐利、更有速度感，使用深海蓝、亮青和少量电光紫。小尺寸版本只保留鲸头、镜像包与一条轨迹。

### C. 鲸尾信标

通过几何负形组合 `I`、`P`、鲸尾和传输箭头，不绘制完整鲸鱼。整体为高对比、低细节的品牌符号，以深蓝底和冰蓝主体为主。该方案优先保证 16–32 px 任务栏图标的辨识度。

## 平台适配

### macOS

- 1024×1024 圆角方形画布，主体位于安全区内，保留系统缩放余量。
- 使用柔和的空间层次和有限渐变，不模拟过度写实的玻璃或金属。
- 输出标准 `.icns` 及各级 PNG 源文件。

### Windows

- 使用更直接的轮廓和更高的前景/背景对比度。
- `.ico` 包含 16、24、32、48、64、128、256 px；16–32 px 使用简化图形。
- 快捷方式与任务栏版本不得依赖外圈细描边。

### 通用品牌位

- 输出透明背景独立符号，用于关于窗口、README、GitHub 发布页等。
- 每套提供横向“鲸舟 / ImagePorter”组合；中文为主名称，英文作为产品名或副标。
- 提供适配亮色与暗色背景的版本。

## 首轮预览与选型

首轮先生成三套 1024×1024 图标概念，并制作统一尺寸的并排对照。评估维度为：产品含义、品牌独特性、macOS 观感、Windows 小尺寸辨识度以及与现有蓝白灰 UI 的一致性。用户选定或要求调整某套方向后，再制作完整平台文件与品牌组合，避免对未选方向进行无效的格式加工。

## 验收标准

- 三套方案第一眼可区分，但都能归属于“鲸舟 / ImagePorter”。
- A、B 在不看文字时能识别出鲸鱼与搬运/容器概念。
- C 在 16 px 下仍保持单一、稳定的轮廓。
- 所有主图标不含错误文字、水印或第三方商标。
- 最终选中方案具备透明符号、亮暗版本、PNG、`.icns`、`.ico` 和横向 Logo。
